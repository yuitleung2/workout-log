# Workout Log

A phone-friendly workout tracker. Each entry saves the date, exercise, weight in kilograms, reps per set, and number of sets. A chart updates when workouts are saved or imported and shows the top logged weight by date for squat (SQ), bench press (BP), and deadlift (DL), over the latest 12 lifting dates. Entries are stored in the browser on the device; there is no account or server.

## Try it on a computer

Open `index.html` in a modern browser. Add an exercise and it will appear in the workout history.

## Use it on an iPhone

With GitHub Pages enabled, open <https://yuitleung2.github.io/workout-log/> in Safari, tap **Share**, then **Add to Home Screen**. Load it once while online; the app shell can then work offline.

Workout history stays in the same Safari browser on the same device. Use **Export CSV** to download a backup before changing phones or clearing website data. Use **Import CSV** to restore that backup; matching workouts already saved on the device are skipped, so importing the same backup again does not add duplicates.
